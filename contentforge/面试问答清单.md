# 面试问答清单 · ContentForge

> 按"通用 Agent 应用开发(15-30k)"高频问题准备。答法：先一句结论，再讲你的做法与取舍。

## A. 架构与流程
1. **这个项目整体怎么流转的？**
   链接/完整文案 → 来源解析与事实摘要 → Analyst 拆内容结构 → Ideation 生成 3 个原创角度 → Writer 写脚本 → Director 做分镜 → Reviewer 审主题与事实 → 人工审核 → 资产包；审核通过后可选渲染和发布复盘。
2. **为什么选 LangGraph 而不是 LangChain 链式/纯脚本？**
   需要**循环**(审稿打回)、**条件路由**、**状态可checkpoint续跑**、可观测；LangGraph 用 StateGraph 显式表达图与状态，比隐式链式更适合复杂 Agent。
3. **6 个 Agent 之间怎么协作？**分工型(各司其职) + 评审型(Reviewer) + 复盘型(Replier)；LangGraph 节点即 Agent，数据经 State 传递。
4. **任务失败怎么办？**
   节点异常 → invoke 外层捕获 → job 标 failed/manual_required、落 error 事件；LLM 调用内置重试；Reviewer 耗尽仍生成资产包但标记人工复核，不默认出片。
5. **checkpoint 怎么用的？**SqliteSaver，thread_id=job_id，每步落盘；同 id 可继续/回溯状态；也用于"任务中断恢复"叙事。

## B. LLM/结构化/幻觉
6. **模型怎么选？**SiliconFlow 统一网关；结构化 JSON 用 DeepSeek-V3（实测 Qwen2.5-7B 不遵循 schema，会输出退化内容）；Embedding BGE-M3、ASR SenseVoice、TTS CosyVoice。
7. **怎么保证模型输出是合法 JSON？**response_format=json_object + 解析容错(去围栏/截首尾/多层嵌套) + 解析失败重问一次。
8. **怎么防"审稿乱放行/打回"？**Reviewer 双保险：规则硬检(标题长度/段数/每段字数/违禁词) 是强约束，LLM judge 只做软打分。
9. **幻觉怎么缓解？**没有有效来源时禁止调用 LLM；脚本必须保持主题一致并有事实支撑；Reviewer 对无依据数字、案例和换题直接 hard 打回。

## C. RAG/记忆/检索（常被引申问）
10. **经验库是什么，为什么不直接用关键词？**每条经验向量化(bge-m3)，按主题语义召回；关键词召回不了"同义不同词"的经验。
11. **短期 vs 长期记忆的取舍？**短期=任务内状态(checkpoint)，长期=跨任务经验(向量库)；短期要精确，长期要可召回、可淘汰。
12. **你的 RAG 项目和医疗毕设的区别/进步？**毕设是"文档问答被动检索"；这里是"知识(经验)驱动生成+闭环写入"，是 Agentic 的记忆回流，不只检索。

## D. 数据/合规/工程
13. **采集 B站合规吗？**只读、匿名、低频、带 UA、对 -412 退避；发布走人工不上传反爬；只对"自己发布的视频"拉数据 → 体现风控/合规意识（这正是企业端关心的）。
14. **版权问题怎么答？**源视频只用于理解主题和结构；系统输出原创脚本、分镜和内容资产，不直接搬运源视频画面。
15. **为什么发布要人工？**平台风控 + 人机协同本就是企业落地标准动作（安全可控），自动化只到"发布包+一键"，并留接口可扩展官方 API。
16. **并发/长任务怎么办？**后台线程执行、任务状态机、事件落库、SSE 增量拉取(event_id)，支持任务列表与重放。

## E. AI Coding/SDD（JD 高频）
17. **说说你的 AI Coding 开发方式。**先写 Spec(范围/决策/DoD) → 建隔离 conda 环境 → 垂直切片打通最险链路(采集/ASR/出片) → 再上 LangGraph → 探针验证每个外部环节 → pytest 锁纯逻辑 → 文档同步；踩过的坑(Qwen不遵循JSON/edge-tts被墙/GBK stdout)都沉淀成文档。
18. **"用 AI 构建 AI"体现在哪？**README 有 SDD 开发日志；把 agent 编排、结构化输出、审稿这类经验复用到了"如何指挥 AI 编程工具"上。

## F. 反问与延伸
19. **项目可扩展点？**多 BVID 队列、失败重试+告警、经验库淘汰与去重、完播率埋点、切换视频号/公众号渠道(adapter 已抽象)。
20. **最有挑战的部分？**外部依赖(平台反爬/ASR/TTS/出片)都不可控 → 用"探针+adapter+缓存+兜底"把不确定性挡在边界外，这是工程化关键。
