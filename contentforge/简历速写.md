# 简历速写 · ContentForge 内容策划与分镜 Agent

> 项目定位：**LangGraph 多智能体内容资产生产工作流**（自研）
> 技术栈：Python / LangGraph / DeepSeek-V3 / BGE-M3 / FastAPI+SSE / MCP / SQLite / ffmpeg

## 1. 项目简介（一句话放最顶）

> 用 LangGraph 编排多角色 Agent，把链接或完整文案转换为"事实摘要→3个原创角度→脚本→分镜→审核→**内容资产包**"，视频渲染为审核后的可选能力。

## 2. 简历 Bullet（Star 结构，每条都能展开追问）

1. **多智能体编排**：用 LangGraph(StateGraph/条件边/checkpoint) 编排分工型、评审型和复盘型 Agent；Reviewer 从主题一致性、事实支撑、原创性和合规性检查，不过审带意见打回 Writer（≤2 次）。
2. **两级记忆 + 自优化闭环**：短期用 SqliteSaver checkpoint(thread_id=job_id) 可续跑可回溯；长期向量经验库(BGE-M3+余弦)承接复盘沉淀；Writer 每次写作自动检索同主题经验注入提示词，形成"数据回流→复盘→下次更好"的闭环（可演示曲线/经验引用）。
3. **内容资产包**：源链接/完整文案 → 事实摘要 → 3 个原创角度 → 主脚本 → 分镜 → 发布信息；输出 `asset_pack.json` 和 `content_assets.md`。
4. **可靠性与人工审核**：平台风控页识别、分享文案兜底、空来源禁止创作；支持通过、打回重写、编辑后再审，审核通过后才允许可选渲染。
5. **可观测与工程化**：FastAPI + SSE 实时 trace 控制台、SQLite 任务/事件/指标存储、APScheduler 定时回流；pytest 67 用例。
6. **MCP + 评测工具链**：提供 `python -m forge.mcp_server`，暴露任务、trace、经验库和评测工具；`forge.evalkit` 统计规则通过率、Review 通过率和失败原因。
7. **AI Coding/SDD 开发方式**：以 Spec-Driven 方式开发，先固定范围和验收标准，再做垂直切片与真实接口验证。
