## 1. 目标与一句话定位

多智能体短视频内容工厂：爆款拆解 → 多 Agent 协作改写/审稿/出片 → 半自动发布 → 数据回流复盘，
用 LangGraph 编排，作为「通用 AI Agent 应用开发岗(15-30k)」简历旗舰。

## 2. 分层架构与代码地图

```
forge/
├─ config.py            # 配置加载(config.yaml + .env)
├─ llm.py               # SiliconFlow/DeepSeek 统一 LLM + Embedding 封装
├─ channels/bilibili.py # B站采集：榜单/详情/音频流
├─ transcript.py        # 文案提取链：CC字幕 → 音频ASR(SenseVoice)
├─ analyst.py           # AnalystAgent：爆款 → 结构化"爆款DNA"
├─ writer.py            # WriterAgent：DNA+经验库 → 新脚本
├─ reviewer.py          # ReviewerAgent：规则 + LLM 审稿打分（打回重试）
├─ media.py / tools/    # 成片：CosyVoice TTS + PIL 卡片 + ffmpeg
├─ pipeline.py          # [旧] 垂直切片单脚本编排（保留参照，不再扩展）
├─ store.py             # SQLite 任务/事件存储（SQLAlchemy）
├─ graph.py             # [新] LangGraph StateGraph + checkpoint + 运行入口
├─ agents/              # [新] LangGraph 各节点实现（转发到上面模块 + 发事件）
└─ server/              # [新] FastAPI 控制台 + SSE 实时 trace + 任务管理
```

**两类编排并存**：`pipeline.py`(线性，已通) 与 `graph.py`(LangGraph，当前主开发线)。
将来删除 pipeline 或仅留作 no-framework 对照。

## 3. LangGraph 生产主流程（当前实现目标）

```
START → source_fetch(B站元信息+文案提取)
      → analyze(dna)
      → write(script) ──(≤2次打回)──→ review(规则+LLM judge)
                                        │ pass / 重试耗尽(带人工复核标记)
                                        ▼
                              producer(出片) → publish_prep(发布包) → END
```
- 条件路由：review 不通过且 rewrite_count<2 → 回 write（带 feedback）；耗尽 → 仍出片但
  标记 `manual_review=true`（安全兜底，绝不让任务空死）。
- 短期记忆：LangGraph SqliteSaver checkpoint（thread_id=job_id，可续跑/可查）。
- 任务状态与事件：SQLite `jobs` + `job_events`，SSE 按 `event_id > last` 推送实时 trace。
- 长期记忆(经验库) / 数据回流(复盘Agent)：D8-10 阶段加入，先预留 store 结构。
